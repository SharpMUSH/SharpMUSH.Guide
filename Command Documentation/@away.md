# @away
`@away <player>[=<message>]`

If `<message>` evaluates to something non-null, it is shown to anyone who pages `<player>` while `<player>` is not connected, in place of "`<player>` is not connected."

### Example
```sharp
> @away me=I'm not here, please send me @mail instead.
```
