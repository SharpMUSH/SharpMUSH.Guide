# lcstr()
# lcstr2()
`lcstr(<string>)`<br>
`lcstr2(<string>)`

  Returns `<string>` with all letters converted to lowercase.

  lcstr2() does the same thing, except that ansi colors and other markup are stripped.

  Example:
```sharp
say lcstr(Foo BAR bAz)
You say, "foo bar baz"
```
