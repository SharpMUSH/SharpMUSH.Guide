# Vector functions
  These functions operate on n-dimensional vectors. A vector is a delimiter-separated list of numbers (space-separated, by default):

|              |              |              |              |              |
|--------------|--------------|--------------|--------------|--------------|  
| [VADD()]     | [VCROSS()]   | [VDIM()]     | [VDOT()]     | [VMAG()]     |
| [VMAX()]     | [VMIN()]     | [VMUL()]     | [VSUB()]     | [VUNIT()]    |
